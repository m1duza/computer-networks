Самостоятельная работа

Компьютерная сеть — это соединённые устройства, которые обмениваются данными.
Топологии: шина, звезда, кольцо.
LAN — сеть на небольшой территории
WAN — сеть на большие расстояния.
В OSI 7 уровней: физический, канальный, сетевой, транспортный, сеансовый, представления, прикладной.
Коммутатор работает на канальном уровне, маршрутизатор на сетевом.
В модели TCP/IP обычно 4 уровня: сетевого доступа, интернет, транспортный, прикладной.
Соответствие: OSI 1–2 → доступ к сети; OSI 3 → интернет; OSI 4 → транспортный; OSI 5–7 → прикладной.
TCP.
это уникальный аппаратный идентификатор, который присваивается каждому сетевому интерфейсу UDP.
В битах: 48 бит.

Часть B. IPv4
192.168.10.130 = 11000000.10101000.00001010.10000010.
Класс B.
Да. 192.168.1.1 входит в частный диапазон 192.168.0.0–192.168.255.255.
Для 192.168.1.0/24:
маска: 255.255.255.0;
доступно хостам: 254 адреса;
сеть: 192.168.1.0;
broadcast: 192.168.1.255.
Для 10.0.0.0/30: всего 4 адреса, для устройств пригодны 2.
Шлюз по умолчанию — маршрутизатор, через который устройство отправляет данные в другие сети.
Часть C. MAC-адреса
а) корректный;
б) корректный;
в) корректный;
г) некорректный: только 5 байт;
д) некорректный: 7 байт;
е) некорректный: G не является шестнадцатеричным символом.
OUI: A4:5E:60; NIC: 12:34:56; адрес unicast, младший бит первого байта равен 0.
Широковещательный MAC отправляет кадр всем устройствам в локальной сети: FF:FF:FF:FF:FF:FF.
MAC используется в локальной сети, IP — для связи между сетями. MAC обычно относится к сетевой карте, IP может меняться. MAC работает на канальном уровне, IP — на сетевом.
Коммутатор запоминает MAC-адреса и порты в таблице. По ней он отправляет кадры на нужный порт.
Часть D. Маршрутизация
Маршрутизация — выбор пути для пакета. Маршрутизатор пересылает пакеты между сетями.
Таблица содержит сеть назначения, маску/префикс, интерфейс и, возможно, следующий маршрутизатор.
а) 192.168.1.55 → Fa0/0;
б) 10.5.5.5 → Fa0/1;
в) 8.8.8.8 → Fa0/2, маршрут по умолчанию.
Выбирается маршрут с самым длинным совпадающим префиксом, то есть самый точный.
Статические маршруты задают вручную. Динамические маршруты устройства изучают автоматически. Пример протокола — OSPF.
Часть E. 
Для сети 172.16.0.0/16:
новая маска: /23 (255.255.254.0), в ней 510 адресов для хостов;
получится 128 подсетей;
первая подсеть: сеть 172.16.0.0, первый хост 172.16.0.1, последний хост 172.16.1.254, broadcast 172.16.1.255.
Компьютер создаёт HTTP-запрос. HTTP данные передаются через TCP, затем добавляется IP-адрес сервера. Далее данные помещаются в кадр Ethernet с MAC-адресами. На локальном участке MAC нужен для доставки кадра, IP — для доставки пакета к серверу. Маршрутизаторы пересылают пакет дальше, а каждый участок сети использует свои MAC-адреса
