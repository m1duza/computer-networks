# Локальная сеть: MAC-адреса и соединение компьютеров

## 1. Цель работы

Изучить принцип соединения компьютеров в локальной сети, назначение MAC-адресов и работу коммутатора. Рассмотреть возможные ошибки сетевого соединения и способы их устранения.

## 2. Схема сети

В сети используются три компьютера (PC1, PC2, PC3) и один коммутатор (Switch 2960).

Каждый компьютер подключён к отдельному порту коммутатора с помощью медного прямого кабеля (Copper Straight-Through).

## 3. IP-адресация

Для проверки связи компьютерам назначены следующие IP-адреса:

| Устройство | IP-адрес     | Маска подсети |
| ---------- | ------------ | ------------- |
| PC1        | 192.168.1.10 | 255.255.255.0 |
| PC2        | 192.168.1.11 | 255.255.255.0 |
| PC3        | 192.168.1.12 | 255.255.255.0 |

Все компьютеры находятся в одной IP-подсети.

## 4. MAC-адреса

MAC-адрес — это аппаратный адрес сетевого интерфейса, используемый для передачи кадров в локальной сети Ethernet.

Коммутатор изучает MAC-адрес источника входящих кадров и сохраняет информацию о соответствующем порте в таблице MAC-адресов.

Для просмотра MAC-адресов компьютеров используется команда `ipconfig /all`. Для просмотра таблицы на коммутаторе Cisco используется команда `show mac address-table`.

| Устройство | MAC-адрес                 | Порт коммутатора |
| ---------- | ------------------------- | ---------------- |
| PC1        | Указать фактический адрес | Fa0/1            |
| PC2        | Указать фактический адрес | Fa0/2            |
| PC3        | Указать фактический адрес | Fa0/3            |

## 5. Проверка соединения

Для проверки доступности PC2 с компьютера PC1 используется команда:

`ping 192.168.1.11`

Получение ответов свидетельствует об успешном обмене IP-пакетами между устройствами.

## 6. Возможная ошибка и её устранение

**Ситуация:** компьютер не может обмениваться данными с другими устройствами сети.

**Возможная причина:** сетевой кабель не подключён или подключён к неправильному порту.

**Способ исправления:**

1. Проверить подключение кабеля к компьютеру и коммутатору.
2. Убедиться, что сетевой интерфейс включён.
3. Проверить IP-адрес и маску подсети.
4. Повторно выполнить команду `ping`.

После устранения неисправности необходимо повторить проверку соединения.

## 7. Вывод

В ходе работы рассмотрено подключение компьютеров к коммутатору, назначение IP- и MAC-адресов, а также принцип изучения MAC-адресов коммутатором. Рассмотрена возможная неисправность сетевого подключения и способ её устранения.
