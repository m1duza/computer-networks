### tcp.udp1.pptx — транспортный уровень, UDP и TCP

Транспортный уровень обеспечивает связь между приложениями на разных устройствах, а для адресации использует порты.  
Порты бывают хорошо известные, зарегистрированные и динамические.  
UDP передаёт отдельные дейтаграммы без установки соединения и не гарантирует доставку или порядок сообщений.  
Из-за этого UDP работает быстрее и подходит для коротких запросов и ответов, например для DNS.  
TCP устанавливает соединение и надёжно передаёт поток байтов в нужном порядке.  
Для этого он использует подтверждения, повторную отправку, скользящее окно и управление потоком.  
TCP также регулирует скорость передачи при перегрузке сети и устанавливает соединение с помощью трёхкратного рукопожатия.  
Для приложений транспортный уровень доступен через сокеты. :codex-file-citation{path="/Users/ivan/Downloads/tcpudp 3/tcp.udp1.pptx" purpose="source"}

### tcp.udp.2.pptx — сравнение TCP и UDP

Транспортный уровень передаёт данные между приложениями и делит их на сегменты.  
TCP обеспечивает установку соединения, подтверждение доставки, правильный порядок данных и управление потоком.  
UDP не устанавливает соединение, не восстанавливает потерянные данные и не контролирует порядок доставки.  
Поэтому UDP создаёт меньшую нагрузку, а TCP подходит, когда важна надёжность.  
Для TCP и UDP используются номера портов, которые помогают передать данные нужному приложению.  
Сочетание IP-адресов и портов образует сокет, по которому можно определить соединение.  
Соединение TCP начинается с обмена SYN, SYN-ACK и ACK, а завершается специальными управляющими сообщениями. :codex-file-citation{path="/Users/ivan/Downloads/tcpudp 3/tcp.udp.2.pptx" purpose="source"}

### tcp.udp.3.ppt — основы UDP и TCP

UDP использует порты, чтобы различать приложения и передавать данные нужному процессу.  
Популярным службам назначают стандартные номера портов, например DNS использует порт 53, DHCP — 67, а TFTP — 69.  
Каждая UDP-дейтаграмма несёт отдельное сообщение, но протокол не гарантирует его доставку.  
TCP надёжно передаёт данные и нумерует байты, чтобы получатель мог собрать их в правильном порядке.  
TCP применяет скользящее окно, подтверждения и тайм-ауты для управления передачей.  
В отличие от UDP, TCP не используют для широковещательной и групповой передачи.  
Выбор между TCP и UDP зависит от того, что важнее приложению: надёжность или простота и скорость. :codex-file-citation{path="/private/tmp/tcpudp_extract/tcp.udp.3.pptx" purpose="source"}
